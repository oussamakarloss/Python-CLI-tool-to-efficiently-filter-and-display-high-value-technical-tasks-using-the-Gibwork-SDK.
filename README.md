 # 🚀 Gibwork Enterprise SDK & CLI Task Filter

An automated CLI application and SDK interface built with Python designed to fetch live tasks from Gibwork endpoints, filter out promotional/spam listings, and highlight high-value technical tasks for developers.

## 📌 Features

- **Automated API SDK Simulation**: Connects and authenticates with Gibwork endpoints (`/v1`).
- **Advanced Filtering Engine**: Automatically scans and strips out marketing, social media, and spam tasks.
- **Developer-Centric CLI Output**: Displays filtered high-value technical tasks (Development, Backend, Smart Contracts) with IDs and rewards clearly formatted.
